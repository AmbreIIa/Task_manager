## Відповіді на контрольні запитання

1. **Що таке `enctype="multipart/form-data"` і чому його обов’язково треба використовувати в тегу `form` для файлів?**
   Це атрибут, який вказує браузеру передавати дані форми у вигляді бінарного потоку (MIME). Без нього браузер відправляє лише назву файлу як текстовий рядок у `$_POST`, а сам вміст файлу не завантажується.

2. **Які ключі завжди присутні в масиві для конкретного файлу в `$_FILES`? Опишіть призначення ключа `tmp_name`.**
   У масиві присутні 5 ключів: `name`, `type`, `tmp_name`, `error`, `size`.
   Ключ `tmp_name` містить шлях до тимчасової директорії сервера, куди PHP зберігає завантажений файл на час виконання поточного запиту.

3. **Чому файли не зберігаються одразу у вашій папці проєкту після натискання Submit, а містяться в тимчасових директоріях операційної системи (`tmp_name`)?**
   Це зроблено для безпеки та економії дискового простору. Якщо файл не пройде валідацію або під час завантаження станеться помилка, PHP автоматично видалить його з `tmp_name`, не засмічуючи проєкт.

4. **Для чого ми використовуємо функцію `move_uploaded_file()`? Чому не можна просто скопіювати файл звичайною функцією `copy()` без перевірок безпеки?**
   `move_uploaded_file()` перевіряє, чи файл дійсно завантажено через легітимний HTTP POST-запит. Звичайна `copy()` цього не перевіряє, що створює ризик атаки зі зчитуванням або підміною системних файлів сервера.

5. **Які потенційні загрози несе дозвіл користувачам “завантажувати будь-що” на сервер (без перевірки розширення чи типу)?**
   * **RCE (Remote Code Execution):** завантаження `.php` файлів дозволяє зловмиснику виконати довільний код на сервері.
   * **DoS (Denial of Service):** завантаження файлів гігабайтного розміру вичерпує пам'ять на диску.
   * **XSS:** завантаження `.html` чи `.svg` файлів із шкідливими JS-скриптами.
   * **Перезапис файлів:** можливість випадково або навмисно підмінити робочі файли проєкту.
